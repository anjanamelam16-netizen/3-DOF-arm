Multibody dynamics of a 3-DOF arm: CAD → URDF → MuJoCo

A small revolute arm (turret yaw + shoulder pitch + elbow pitch, 0.58 m reach, 0.5 kg payload) taken from
parametric CAD through URDF into MuJoCo, then used for six studies: model validation against an independent
Newton-Euler solver, trajectory control, system identification, contact and friction, Monte Carlo robustness,
and a ROS 2 bridge for RViz.
